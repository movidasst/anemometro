# Anemómetro Ocupacional · MOVIDA SST+ MAV–PRO 600 SIM

Simulador didáctico independiente de La Movida de SST Plus para practicar medición de velocidad del aire en higiene ocupacional y ventilación.

## Modos

- **HOT WIRE**: bajas velocidades y ambiente ocupacional.
- **VANE**: corrientes definidas, rejillas y salidas de ventilación.
- **PITOT**: modo avanzado para recorrido de puntos en ductos.

## Funciones didácticas

- LIVE, HOLD, MIN, MAX y AVG.
- Muestreo simulado a 2 Hz.
- Promedio temporal, desviación estándar e intensidad de turbulencia `TU = SD / v̄ × 100`.
- Perfil vertical de medición para persona sentada/de pie según ISO 7726.
- Promedio multipunto.
- Caudal didáctico `Q = v̄ × A`.
- Recorrido Pitot con 12 puntos circulares o 25 rectangulares.
- Memoria local.
- Acceso por cédula + código de integrante mediante el RPC `acceso_integrante`.
- Sesión de 20 minutos y protección básica de intentos.

## Base técnica usada para diseño didáctico

- ISO 7726:1998 / EN ISO 7726:2001.
- Manual Testo 425, anemómetro de hilo caliente.
- Manual Testo 410-1, anemómetro de hélice.
- ISO 3966:2008 para el concepto del modo Pitot. Esta edición no se presenta como vigente.

> **SIMULACIÓN DIDÁCTICA.** No sustituye mediciones de campo, calibración, evaluación de incertidumbre ni aplicación completa de normas técnicas.
